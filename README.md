
# 🎬 MovieWatch – Movie Watchlist App

A React-based Movie Watchlist application that helps users discover movies, search for titles, filter by genre, and manage their personal watchlist.

## ✨ Features

- User sign-up page
- Movie listing with posters and ratings
- Search movies by title
- Filter movies by genre
- Add movies to your watchlist
- Remove movies from your watchlist
- Prevent duplicate entries
- Responsive and cinematic user interface

## 🛠️ Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Axios
- Vite
- IMDb API through RapidAPI

## 🚀 How to Run the Project

1. Clone this repository:
   ```bash
   git clone https://github.com/aljannath2001-jafi/movie-watchlist-app.git
   ```

2. Open the project folder:
   ```bash
   cd movie-watchlist-app
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Create a `.env.local` file in the project root and add your own API key:
   ```env
   VITE_RAPIDAPI_KEY=your_api_key_here
   ```

5. Start the development server:
   ```bash
   npm run dev
   ```
